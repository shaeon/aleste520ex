                         STARTING MSX-DOS

  Download the operating system can be in several modes D: PC ALESTE 520 EX
has following Modes work in operating system MSX-DOS, that set at
initialization.

     - STANDARD MODE -- set on default.
          Supports work with drives A: and B: (with absence drive B:
          supported logical Drives on one drive), the configuration
          of the electronic drive read of hours real-time.
          When presence on e disk File operating reference system with
          him made boot in Otherwise case download is with drive,
          defined in SETUP.
     - Treatment of one disk drive - is included in the retention of key
       CTRL after reset. In This mode used only one physical drive A:
       (regardless of whether the second). This some increases volume memory
       available program user. Initializing ramdisk and logic downloads
       OS does not differ from the standard treatment.
     - To boot from ROM drives - included at retention keys ALT after reset.
       Mode completely similar standard, except that the loading OS is disk
       defined in SETUP. Mode useful for Rescue files from the ramdisk if
       the load with it on any reason is not made.
     - MODE EMERGENCY LOADING - included at retention ESC key after reset
       and is used in case failure hours of real time. When This download
       OS is always with the A: drive and the RAM disk is not initialized.
       NOTE: Retention keys ESC leads also to activate avarinoy boot in BIOS
       and ROM loader.
     - EMERGENCY DOWNLOAD MODE With INITIALIZE ELECTRONIC DRIVE - included at
       retention combination keys ALT + ESC. It differs from the previous one,
       which is initialized e Drive up 256K regardless of the settings in SETUP.
       When need allowed joint inclusion multiple modes.
